# 我的第一個前後端程式

HTML／JavaScript + Node.js 24 + SQLite。無須 npm install。

本機執行：`HOST=127.0.0.1 PORT=8080 node server.js`，瀏覽 http://127.0.0.1:8080。

請將本目錄的檔案提交到 GitHub 儲存庫根目錄。部署系統將取得固定 commit，使用操作員控制的隔離建置配方；請勿自行填寫服務密鑰、Docker socket 或映像憑證。

這是沒有登入的教學範例，僅使用虛構資料。學生自助部署與安全預覽尚未開放；本機資料請勿提交。200 MB 的部署程式／檔案配額正在接線，目前尚未生效。
